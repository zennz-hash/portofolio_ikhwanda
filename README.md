## 🌟 Key Highlights & Features

- **Architectural Aesthetic**: Brutalist-editorial typography with dynamic ambient light and soft cursor-tracking shadow bloom.
- **Bilingual Internationalization (i18n)**: Seamless English (`EN`) and Indonesian (`ID`) language switcher with real-time reactive translations.
- **Native View Transitions**: Smooth, cinema-grade transitions between chapters (`Home`, `About`, `Skills`, `Projects`, `Experience`).
- **Interactive Project Showcase**:
  - **AriseHash**: AI Architecture Engine & In-Browser Code Sandbox ([arisexhash.xyz](https://arisexhash.xyz)).
  - **Calcu.id**: Multi-Utility Financial, Tax & Productivity Calculation Engine ([calcu.my.id](https://calcu.my.id)).
  - **ShadowRoll**: Confidential DeFi Payroll Protocol powered by Arbitrum Sepolia & iExec Nox ([shadow-roll.vercel.app](https://shadow-roll.vercel.app)).
- **Integrated CV Modal & Download**: Direct PDF preview with celebratory micro-interactions and download trigger.
- **Ultra-Lightweight & Fast**: Built with React 19 and Vite 8 for sub-second page loads and zero layout shift.

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/zennz-hash/MyPortofolio.git

# Enter project directory
cd MyPortofolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```

The optimized static production bundle will be generated inside the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## 🌐 Custom Domain Setup (`is-a.dev`)

To connect a free custom developer domain like `ikhwanda.is-a.dev`:
1. Deploy this repository to [Vercel](https://vercel.com) or [Cloudflare Pages](https://pages.cloudflare.com).
2. Fork [is-a-dev/register](https://github.com/is-a-dev/register).
3. Add `domains/ikhwanda.json` pointing to your Vercel CNAME (`cname.vercel-dns.com`).
4. Submit a Pull Request to register your domain.
